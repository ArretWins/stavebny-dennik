## Global Rules
- MVP ships only Slovak (`sk-SK`), but all visible strings must use translation keys.
- UI must follow `DESIGN_SYSTEM.md` and the source concept `mockup-stavebny-dennik-mvp.png`.
- MVP is evidence-grade, not marketed as a certified official state e-denník.
- No billing, OCR receipts, eID signing, iOS release, or government-system integration in MVP.
